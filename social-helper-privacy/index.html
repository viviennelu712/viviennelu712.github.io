Vivian 社群小幫手
隱私政策與資料刪除

生效日期：2026 年 10 月 28 日

適用範圍

「Vivian 社群小幫手」（包含「Vivian 社群小幫手-IG」）由 Vivian 維護，透過 Meta 官方 API 協助管理 Vivian 自己的 Instagram 與 Threads 帳號 @vivienne.lu.ww。這是自用工具，目前不提供其他帳號註冊或代管服務。

存取哪些資料、用來做什麼

在帳號授權與平台允許的範圍內，工具可能取得帳號識別碼、使用者名稱、帳號類型、自己的貼文與媒體資料、公開留言與回覆，以及 Instagram 對話識別碼、參與者與更新時間。只有經 Vivian 明確確認為可處理的觀眾對話，才會讀取其訊息內容。

這些資料用於確認帳號、管理自己的內容、整理觀眾提問、準備回覆與保存處理紀錄，避免重複回覆。發布或回覆須經操作者授權及工具的送出控制。平台授予權限不代表工具已啟用所有功能。

工具不索取社群帳號密碼；朋友、家人、陪跑學員及尚未分類的私人對話，不由此工具讀取內文或起草回覆。Threads 私訊目前未接入此工具。

儲存與資料接收者

存取權杖保存在 Vivian 的 Mac 系統鑰匙圈。必要的讀取結果、草稿及操作紀錄存於本機工作資料夾，與這個公開政策網頁分開保存，不會隨政策頁公開。

社群操作直接連接 Meta 官方 API，不使用第三方社群代管服務。當操作者使用 Codex／ChatGPT 或 Claude 協助整理或起草時，所選取的內容可能傳送至 OpenAI 或 Anthropic，依各服務的資料處理政策及帳號設定處理；因此並非所有處理都只發生在本機。

Vivian 不出售這些社群資料，也不以此工具進行廣告投放。除提供上述功能、依法應配合的要求或本人另行同意外，不主動向其他接收者提供資料。

保存與保護

資料只供上述管理用途使用。必要紀錄可能保存至用途結束、人工清理或收到刪除要求為止；目前沒有固定天數的自動清除功能。資料應透過電腦帳號權限、系統鑰匙圈及工具的讀取與送出限制保護；平台撤銷授權後，工具應停止後續 API 存取。

撤銷授權與申請資料刪除

帳號擁有人可在 Instagram 的「應用程式和網站」或 Threads 的網站權限設定中，移除此應用程式的存取權。撤銷授權會停止後續存取，已保存的本機資料需另外刪除。

若要查詢、更正或刪除本工具保存的本人資料，請私訊 Instagram @vivienne.lu.ww，註明「社群小幫手資料刪除」及相關帳號或貼文連結。請勿在公開留言提供私人訊息或身分文件。Vivian 確認請求者身分及資料範圍後，會移除可識別的本機內容與草稿，並回覆處理結果；必要的最小防重紀錄或依法須保留的部分會另行說明。

刪除本機資料不會刪除 Instagram 或 Threads 上的原始貼文、留言或訊息；如需刪除平台上的內容，請使用該平台提供的功能。
